# Single source of truth for the mod build nodes (docs/bridge/README.md, "Support selection").
#
# Read by: settings.gradle (project tree), the node build scripts, scripts/dev-env.sh and scripts/dev-env.ps1
# (JDK per node), scripts/compile-matrix.mjs and .github/workflows/mod.yml (job matrices). Add a node here first,
# nowhere else.
#
# Columns, separated by blanks:
#   id           Node id and Gradle project name: <highest minecraft release>-<loader>. Never used as a version (see README).
#   loader       fabric | quilt | neoforge | forge
#   minecraft    Explicit Mojang release ids the jar CLAIMS to serve (this goes into mod-index.json), comma separated,
#                no ranges, no snapshots. The LAST id is the version the node is compiled against by default.
#   loaderMin    Lowest loader version the jar accepts (Fabric Loader, NeoForge, Forge).
#   java         JDK major that compiles (--release), tests and runs the node. It is also the jar's javaMin.
#   strategy     fabricAddMods | quiltAddMods | fmlMavenRoot | fmlModFolders | forgeClasspath
#   gradleJdk    JDK major Gradle itself runs on for this node: at least java and at least mod.gradleJdkMin.
#                Stonecutter needs 21, Fabric Loom 1.18 needs 25 (also for obfuscated Minecraft versions).
#   matrix       Every Minecraft release the node is meant to serve (docs/bridge/MINECRAFT-API.md), comma
#                separated, ascending. `minecraft` must be a subset: a node claims only what it was built against.
#                scripts/compile-matrix.mjs compiles both ends and one middle release of this list.

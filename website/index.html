What does Pumpkin do?

Pumpkin is an independent launcher for Minecraft: Java Edition. Use it to keep separate game setups, browse mods and modpacks, and launch the one you want to play.

Is it ready to use?

The beta is available now. Get the Windows, Linux (AppImage or .deb) or macOS (.dmg) installer from the download section. Builds are hosted on GitHub and aren't code-signed yet, so Windows and macOS may warn you on first launch. Windows is the primary test platform; Linux and macOS builds haven't yet been tested on real devices. The source is on GitHub too.

Can I play with my usual mods?

Pumpkin installs Vanilla, Fabric, Forge, NeoForge and Quilt. Browse mods and modpacks from Modrinth, CurseForge, FTB and Technic, or import a .mrpack file. Choose the Minecraft version and loader your mods need.

How do I sign in?

Use your Microsoft account in your browser. Mojang has approved Pumpkin for sign-in.

Do I still need to own Minecraft?

Yes. You'll need Minecraft: Java Edition to play. Pumpkin is an independent launcher, not a copy of the game or an official Mojang or Microsoft product.

Installation guide

For Windows 10 or 11, 64-bit. The installer is not code-signed. Only approve a Windows warning if you trust the download from this repository.

  1. Download Pumpkin.Launcher_x64-setup.exe using Get for Windows.
  2. Make sure Microsoft WebView2 Runtime is installed. Pumpkin needs it to display the app.
  3. Open the downloaded .exe. If SmartScreen shows Windows protected your PC, and you trust this repository's download, select More info → Run anyway.
  4. Follow the installer prompts. Pumpkin installs for your Windows user. When installation finishes, open Pumpkin Launcher.

The universal app supports Apple Silicon and Intel. It is ad hoc signed, but not notarized. This beta package has not yet been tested on real macOS devices.

  1. Download Pumpkin.Launcher_universal.dmg using Get for macOS, then open the disk image.
  2. Drag Pumpkin Launcher to Applications. Open Applications and launch Pumpkin from there.
  3. If macOS blocks opening, proceed only if you trust this repository's download. After trying to open the app, go to System Settings → Privacy & Security, find the blocked-app message and choose Open Anyway. Authenticate if asked, then confirm Open. On older macOS versions where available, Control-click or right-click the app in Applications, choose Open, then confirm. Follow Apple's app approval guidance; do not disable system security protections.
  4. On Apple Silicon, Minecraft versions through 1.18.2 need Rosetta 2. Install it when macOS prompts before playing those versions.

For Linux x64. This beta package has not yet been tested on real Linux devices. Pumpkin needs WebKitGTK 4.1 and an available, unlocked Secret Service keyring, such as GNOME Keyring or KWallet, for Microsoft sign-in.

  1. Choose a package. On Debian or Ubuntu, prefer the .deb: your package installer can report missing system libraries. For other distributions, choose the AppImage.
  2. Open a terminal in the folder containing your download. For AppImage, make the file executable and start it: 
    chmod +x Pumpkin.Launcher_amd64.AppImage
./Pumpkin.Launcher_amd64.AppImage
    Alternatively, use the file's Properties to allow executing it as a program, then open it.
  3. If you chose the Debian/Ubuntu package instead, install it with: 
    sudo apt install ./Pumpkin.Launcher_amd64.deb
    Then open Pumpkin Launcher from your applications menu.
  4. If AppImage startup fails, install your distribution's WebKitGTK 4.1 runtime package. If sign-in reports a storage error, make sure your Secret Service keyring is running and unlocked. Package names vary by distribution; Tauri's Linux guidance lists distribution-specific dependencies. You do not need Rust, Node.js, compilers or development headers just to run a release.

Your first launch

  1. Choose Sign in with Microsoft. Use an account that owns Minecraft: Java Edition; Bedrock alone is not enough. Complete sign-in in your browser, or choose Use a code instead.
  2. At How do you want to start?, choose Plain Minecraft → Create and play. Pumpkin downloads the required game files and matching Java runtime automatically; no separate Java or Minecraft installation is needed.
  3. Next time, select your setup in the library and press Play. If you already completed onboarding, use Library → New instance → Custom instance, explicitly set Loader to Vanilla, then choose Create and Play.

If your account has no Minecraft profile yet, open the official Minecraft Launcher once to choose a player name, then return to Pumpkin.

Still having startup or sign-in trouble? Ask in GitHub Discussions and include your operating system and the error message. Never share passwords or sign-in codes.

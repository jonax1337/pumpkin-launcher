2. This website

This website is static and served through GitHub Pages. It does not set cookies, use analytics or advertising services, or load fonts, scripts or images from third-party servers; everything comes from the same address.

When you visit the website, the hosting provider, GitHub, Inc., processes technically necessary connection data (IP address, time, requested file and browser). We have no control over this. The legal basis is Article 6(1)(f) GDPR (secure and stable operation of the website). Further details are provided in GitHub's privacy statement.

When you visit the website, your browser does not send requests to GitHub or other third parties, only to the server delivering the page. In the “Download” section, the installers are simple links to github.com. Only when you click a link does your browser open GitHub, which then processes connection data (such as your IP address) as described in GitHub's privacy statement. Detection of your operating system to highlight the appropriate download takes place only locally in your browser; nothing is transmitted or stored.

3. The launcher

Pumpkin Launcher sends no telemetry and has no trackers. You do not have an account with us. Instances, settings and accounts are stored only on your computer; your Microsoft account's authentication token is stored in your operating system's credential store (Windows Credential Manager, macOS Keychain or a Secret Service such as GNOME Keyring or KWallet).

The launcher connects only to the following services, and only when you use the relevant feature. Each service can see your IP address:

  • Modrinth (api.modrinth.com, cdn.modrinth.com): searches, project pages and downloads of mods and modpacks.
  • CurseForge: searches and project data through a proxy on Cloudflare Workers (pumpkin-curseforge.jonas-laux.workers.dev), which holds the API key and does not store or log anything; Cloudflare technically processes the request, including the IP address for rate limiting. The launcher downloads files directly from edge.forgecdn.net, mediafilez.forgecdn.net and media.forgecdn.net.
  • Feed The Beast (api.feed-the-beast.com, files.feed-the-beast.com, cdn.feed-the-beast.com): modpacks.
  • Technic (api.technicpack.net, www.technicpack.net, cdn.technicpack.net), as well as the pack authors' servers hosting the files, such as Dropbox, GitHub or their own servers.
  • Mojang (piston-meta.mojang.com, piston-data.mojang.com, launchermeta.mojang.com, libraries.minecraft.net, resources.download.minecraft.net, textures.minecraft.net): Minecraft, the Java runtime, libraries, assets and skin textures.
  • Microsoft and Xbox (login.microsoftonline.com, user.auth.xboxlive.com, xsts.auth.xboxlive.com, api.minecraftservices.com): sign-in, profile, skins and capes, only if you sign in.
  • Mod loaders (meta.fabricmc.net, maven.fabricmc.net, meta.quiltmc.org, maven.quiltmc.org, maven.minecraftforge.net, files.minecraftforge.net, maven.neoforged.net, repo1.maven.org): version lists and installers for Fabric, Quilt, Forge and NeoForge.
  • GitHub (github.com, githubusercontent.com): launcher updates, with a silent check shortly after startup and a download at your request.
  • mclo.gs (api.mclo.gs): only after you click “Share log”; the sanitized log is uploaded publicly.
  • Image hosts in project descriptions: images from cdn.modrinth.com, media.forgecdn.net, raw.githubusercontent.com, avatars.githubusercontent.com, user-images.githubusercontent.com, media.githubusercontent.com and i.imgur.com load without asking. The launcher loads images from all other hosts only after you click.

The launcher does not scan mods, modpacks or Technic packs for malware. It checks file sizes and checksums where the provider publishes them.
